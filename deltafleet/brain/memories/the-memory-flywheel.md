# The memory flywheel

The key learning moat. Every human `edited` or `rejected` gate verdict is auto-captured as a keyed client memory candidate; repeated corrections confirm (confidence grows) rather than duplicate. Interventions teach the fleet: the trust curve reduces gating over time, and memory reduces the need for edits at all — so the same correction is never needed twice.
