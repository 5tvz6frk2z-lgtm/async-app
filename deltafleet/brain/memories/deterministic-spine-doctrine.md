# Deterministic spine, agent joints

The core execution doctrine. Anything that can be deterministic MUST be a script — plain code, same input same output, zero tokens. The model is reserved for judgment: classify, summarize, draft in brand voice, decide exceptions. **Numbers in client deliverables come from code, never a model** — a computed figure can't be hallucinated. This is what makes the starter tier economically real at cents per run.
