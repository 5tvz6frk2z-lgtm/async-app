# Delta Fleet

> Delta Fleet is an AI workflow integration studio: we install supervised agent fleets into the tools a business already uses — gated where it matters, measured against a baseline, and run from one console (Agentloop). Six installable "corridors" (workflows): Speed-to-Lead, Inbox & CRM Hygiene, Reporting Autopilot, Content/AEO Engine, Document Intake, and Review & Reputation — plus a read-only $79/month Daily Brief starter. Human judgment on anything brand-visible; agents execute; every action is logged and reversible.

Key facts:
- Positioning: done-for-you AI integration for small and mid-market businesses (10–200 employees), across industries. Not a DIY tool and not a self-serve agent marketplace — we install and operate the workflow, and leave the client a console.
- Execution doctrine: "deterministic spine, agent joints." Anything that can be plain code is plain code (fast, cheap, identical every run); models are reserved for judgment (classify, draft in brand voice, decide exceptions). Numbers in deliverables are computed, never generated by a model.
- Trust model: brand-visible or irreversible actions start behind a human approval gate; gates relax only on measured evidence (a "trust curve"). Two actions never auto-relax: CRM merges and negative-review responses. Every human correction is captured into per-client memory, so the fleet learns and the same edit is not needed twice.
- Specialization cascade (plug-and-play across industries): generic blueprint → industry pack (terminology, standing rules, compliance — e.g. a healthcare pack with PHI guardrails) → client profile (brand/voice, set on the onboarding call) → learned memory.
- The ladder (pricing): Daily Brief ($99 setup + $79/month, or $49/month bring-your-own-API-key; setup credited toward a Recon) → Recon (paid workflow audit → fixed-price plan) → Install ($8,000–$20,000 fixed, one to three corridors live in 30 days) → Flight Ops (managed retainer with a monthly Delta Proof report). Legacy marketing retainer tiers (Scout/Squadron/Armada) still apply to the marketing corridors.
- Measurement: every corridor is measured baseline-vs-current; the AEO corridor additionally runs monthly graded citation audits across ChatGPT, Perplexity, Gemini, Claude and Google AI Overviews (outcome × position × sentiment, k=3 on priority questions), competitor-normalized share of voice, ranked gap briefs. The company dogfoods the AEO corridor on this very site.
- White-label: agencies resell corridor installs under their own brand at wholesale.
