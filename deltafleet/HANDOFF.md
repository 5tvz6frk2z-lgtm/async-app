## 1 · What this business is now (it evolved — follow the arc)

**Delta Fleet (deltafleet.ai)** started as an AI *marketing* agency site (v1–v8), then pivoted (see `PIVOT-PLAN.md`) into an **AI workflow integration studio**: we install supervised agent fleets into a client's existing tools, gated and measured, and leave them a console. Current strategy layers, decided with the owner across sessions:

- **The ladder:** Daily Brief ($99 setup + $79/mo, or $49/mo BYOK) → Recon (paid audit, ~$2k, fee credited from starter setup) → Install ($8–20k fixed, 30 days) → Flight Ops retainer. Affordability at the bottom, moat at the top. No à-la-carte agent marketplace (deliberately rejected — see chat history rationale in PIVOT-PLAN framing).
- **Execution doctrine: "deterministic spine, agent joints."** Anything that can be plain code IS plain code (zero tokens, reproducible); models are reserved for judgment (classify, summarize, draft in brand voice). Numbers in deliverables are computed, never generated.
- **Plug-and-play across industries** via a four-layer specialization cascade: Blueprint (generic) → Industry Pack (JSON data file) → Client Profile (onboarding call) → **Memory** (learned per client, forever).
- **Trust curve:** brand-visible/irreversible actions start approve-gated; ≥20 verdicts with ≤5% intervention earns a relaxation *proposal* a human applies. Two things never relax: CRM merges, negative-review responses.
- **The flywheel (key moat):** every human edit/rejection at a gate is auto-captured as client memory, so interventions teach the fleet. Trust curve reduces gating; memory reduces the need for edits at all.

## 3 · Platform architecture (deltafleet/platform — the crown jewels)

One Node process per client. `npm test` (40 tests) · `npm run demo` → console at :4600.

```
blueprints/*.json  7 corridors (6 install + daily-brief starter). Spec: trigger, agents
                   (callsign/role/model/tools), gates {tool: auto|log|approve}, optional
                   pipeline[] (script/infer steps + $refs), metrics, rollback, entry, tier.
packs/*.json       6 industry packs: terminology, standing rules, urgency, compliance
                   (healthcare pack carries PHI guardrails), corridorHints.
lib/ledger.js      Append-only JSONL; ALL state derived by replay (runs, actions,
                   approvals, metrics, gate overrides, memory). Never mutate events.
lib/gates.js       auto/log/approve classification; approve/edit/reject verdicts resolve
                   parked promises; trustStats() → relaxation proposals; changeGate().
lib/runtime.js     AgentRun (tool loop; parks on approval, resumes w/ edited input,
                   rejection final, AbortController kill, step/token budgets) +
                   AnthropicAdapter (fetch, adaptive thinking, default claude-opus-4-8)
                   + MockAdapter (scripted; tests/demo).
lib/pipeline.js    PipelineRun — hybrid executor: script steps (ScriptRegistry, gated
                   like tools) + infer steps (SINGLE completion, numbers-from-input rule);
                   $trigger/$profile/$results refs.
lib/scripts.js     ScriptRegistry + Daily Brief sim handlers + coverage guard.
lib/memory.js      MemoryEngine: rule/preference/fact/pattern, provenance, confidence,
                   confirms; events in the SAME ledger; enableCorrectionCapture() =
                   the flywheel; retrieve() scoped+ranked+budgeted; consolidate() decay.
lib/packs.js       Pack loader + packContext() prompt lines.
lib/mcp.js         Zero-dep MCP client (Streamable HTTP, JSON+SSE responses, session id).
lib/connectors.js  connectors.json maps fleet tool names → MCP server tools;
                   assertBlueprintsCovered = unmapped tool is a BOOT failure.
lib/triggers.js    5-field cron (dom/dow OR rule) + TriggerEngine + webhook handler
                   (x-fleet-secret; schedule blueprints 409 webhooks).
lib/metrics.js     proofFor (baseline vs current, direction-aware) + opsSummary.
lib/report.js      Delta Proof: reportData (activity in window, proof all-time) +
                   printable HTML. Served at GET /report.
server.js          Wires everything. Flags: --demo --port --data --profile
                   --connectors --triggers --hook-secret. BYOK via profile.byok.
console/index.html Client console: approvals queue (approve/edit/reject), run feed
                   with traces, kill, corridor cards (proof + gates + trust), Client
                   Memory panel (teach/retire), Delta Proof button, demo sortie.
profile.example.json / connectors.example.json  Per-client config templates.
```

**Gotchas:** memory/baseline seeding order (capture `FRESH_LEDGER` before seeds — regression fixed in the Delta Proof commit); killed runs void pending approvals in `Ledger.state()`; tool names use `domain.verb`, translated to `__` on the Anthropic wire; `pkill node server.js` from a compound Bash command kills the shell (exit 144) — run it alone.

## 5b · Fleet Deck (operator suite — `deltafleet/fleetdeck/`, new)

A zero-dep, local-first suite for people who *operate* AI agents (distinct from the platform, which *runs* client fleets). Built end-to-end this session with a sub-agent crew (a research agent verifying MCP/OTel/crawler facts → `RESEARCH.md`; an implementation agent; an adversarial testing agent). **Architecture: one shared spine, many views.** `lib/spine.js` is an append-only JSONL event log with crash-safe load, incremental named projections (each tool registers a view), maintained query indexes, and unforgeable `id/seq/ts/kind` stamps. Every tool is a *view* over it, so a snapshot is internally consistent by construction.

A dozen tools (`lib/`): **Tollgate** (local MCP firewall — deny-by-default per-agent tool scoping with deny as a hard floor across scopes; pins each server's advertised tools and raises CRITICAL drift when a description/title/input-schema changes on an already-approved tool = the tool-poisoning/rug-pull signature; `readOnlyHint` advisory, never a grant). **Flight Recorder** (one timeline; correlates call→result; exports OpenTelemetry GenAI `execute_tool` spans, semconv pinned behind a constant). **Meter** (token/cost rollups by agent/model/day + budget alarms; pure read-model). **Approvals Inbox** (a Tollgate `review` decision is the request, a human resolves it with an `approval.verdict` event; tamper-evident, doubles as compliance evidence). **AI Register** (maps spine events to a swappable law-pack's controls — baseline governance / EU AI Act; honest gaps shown; CSV export). **Preflight** (CI for policy — replay a candidate manifest vs real history, flag UNSAFE if it newly *allows* a previously-blocked call; dry-run an MCP update vs its pin). **Agent-Ready** (scores a page's legibility to AI agents/answer engines; the Agent-Ready Monitor product engine). **Cortex-as-MCP** (`lib/cortex-mcp.js` + `bin/cortex-mcp.js` — wraps the `brain/` second brain as a REAL MCP server over stdio: `memory_search`/`memory_stats`, transport-agnostic core; verified live serving 87 memories; Tollgate can pin+guard it like any MCP server — the capstone tying the two packages together). **Contextsmith** (versioned registry for CLAUDE.md/prompts/skill guidance — content-addressed versions, activate/rollback, LCS line diff; every activation is a spine event so a cost/behavior change correlates with the exact context version live). **Tollgate proxy** (`lib/proxy.js` + `bin/tollgate-proxy.js` — THE enforcement point that makes Tollgate *enforce*, not just observe: a real MCP proxy sitting between client and server that drift-blocks a poisoned tools/list (fail closed) and policy-gates every tools/call (deny→error, review→held, allow→forwarded+recorded). Approvals are single-use AND bound to the reviewed payload. Verified end-to-end over real stdio guarding cortex-mcp; `examples/mcp-config.json` + `examples/manifest.json` make it drop-in for Claude Code). Plus `lib/deck.js` (facade), `lib/seed.js` (demo scenario incl. a live tool-poisoning attack), `bin/fleetdeck.js` (CLI: seed/serve/timeline/alerts/meter/inbox/approve/register/preflight/context/check), `server.js` (JSON API + live-reloads on spine change — an external proxy's traffic appears in the deck live), `ui/index.html` (7-tab operator deck incl. Monitors, theme-aware), `ADR.md` (12 architecture decisions). Then a PRODUCTIZATION phase turned the two endorsed products into actual subscriptions: **Monitor** (`lib/monitor.js` — recurring-check + regression-alert engine; a scheduled `record()` snapshots a target's health onto the spine and alerts only on a worsening *change* = no fatigue; Agent-Ready Monitor rules [score drop, a newly-blocked RETRIEVAL crawler = critical citation-killer, JS-shell = critical, JSON-LD/llms.txt loss] and AI Register Monitor rules [posture slips, control → gap]), **Notify** (`lib/notify.js` — delivers new alerts to Slack/webhook via fetch, zero-dep, redacted logs, dead-channel-tolerant), a cron-friendly `monitor` CLI + a 7th "Monitors" UI tab (sparkline + alerts), and the proxy now PAGES a human on tool-poisoning drift (onAlert → Notify). A research sub-agent (`RESEARCH-MONITORING.md`) drove evidence-based refinements: 16 crawler tokens classified by role (retrieval/training/user/optout — blocking a retrieval bot is the citation-killer), and the EU AI Act pack carries verified dated facts (Art. 50 applies **2 Aug 2026**; Art. 12/14 deferred to 2027/28 by the Digital Omnibus — verify vs the Official Journal). **Zero deps** (grown to 338 tests through the audit below), hardened by an extensive **loop-until-dry correctness audit** — a Workflow-orchestrated crew of parallel hunters (each executing the REAL module against crafted adversarial inputs) + independent verifiers (each re-reproducing before a finding counts), run round after round until a pass finds nothing new. Across **12 rounds it found and fixed ~87 confirmed defects** (roughly half genuine security bugs), each with a labeled `audit<N>:` regression test (`test/audit1.test.js` … `audit12.test.js`). The productive phase was then declared complete: the security-critical core (firewall `decide`/drift, register-engine, contextsmith, preflight) was clean across the final rounds, and the remaining yield is the asymptotic tail — malformed/hostile-input robustness, refinements of earlier fixes, and information-theoretically-bounded legacy-metric-shape edges (one such, a crawler-access legacy-shape false-negative, is documented in `monitor.js` as an accepted limitation because any "fix" reintroduces a false-positive). More rounds would keep surfacing a handful of narrow input-robustness items per pass without a terminating condition; the high-value defects are exhausted. The recurring HIGH classes were closed at the *class* level, not patched one case at a time: the tool-name deny-bypass moved from a Unicode-category blocklist (which invisible chars kept dodging — variation selectors, Hangul fillers, Braille blank, U+FFFC) to a printable-**ASCII allowlist**; the Agent-Ready retrieval-access rule became a single unified list-or-count baseline; the schema-drift canonicalizer became position-aware (schema keyword vs instance-data vs unordered-set). Representative fixes: firewall deny-floor & review-floor bypasses; tool-poisoning blind spots (schema data-array reorder, duplicate-tool-name hiding, non-string description crashing the detector, empty-pin baseline); HITL bypasses (payload-bound single-use approvals, consumed-retry re-approval); audit-trail integrity (a denied call stealing a later result's cost/tokens; spine `query()` silently wrong under null constraints or non-positional seqs); a meter `NaN`/negative/`string` cost silently disabling every budget alarm; a webhook-secret leak in delivery logs; a preflight fail-open on a policy widening. Products endorsed by owner: **Agent-Ready Monitor** ($99–299/mo) and **AI Register** ($49–199/mo) — both with working recurring-monitor + alert-delivery engines. The full planned tool set is built, enforcing, deployable, productized, and adversarially hardened to a degree well beyond typical. Finally, a **full-stack integration verification** drove the real proxy in front of the real cortex-mcp over stdio and traced one run through every surface — CLI (`timeline`/`inbox`/`register`), HTTP API (`/api/timeline`/`/api/otel`/`/api/register`/`/api/snapshot`), the operator UI, and the OTel export (a held write correctly emits an ERROR `execute_tool` span, never an OK one for an action that never ran). That surfaced a self-defeating **example manifest**: a catch-all `"*":{"*":{"review":["*"]}}` floor held even the explicitly-allowed `memory_search` (review is a hard floor unioned across scopes, ADR #6) — so the advertised "read the Cortex brain" demo never reached Cortex. Fixed to a clean three-way policy (read tools allow → forwarded with real answers; writes review → held; else deny) in both `examples/manifest.json` and the Deck config, and shipped `examples/demo-guarded-cortex.mjs` — a zero-dep, runnable end-to-end showcase (real proxy → real MCP server → real policy → one spine → three operator lenses → human approval), wired into the README as the recommended starting point. **338 tests, zero deps.**
