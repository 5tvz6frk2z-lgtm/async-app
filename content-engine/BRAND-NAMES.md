## Registration protocol (do all in one day, before announcing anything)

1. Type the handle into the signup/handle field on YouTube, TikTok, Instagram,
   and Pinterest — web search cannot see dormant/reserved handles, so the signup
   box is the final check.
2. Register all four the same day, plus the .com at any registrar.
3. If one platform blocks the exact handle, fall back to the same name with a
   suffix used consistently everywhere (e.g. `@thelongledgerhq`) — never mix
   different base names across platforms.
